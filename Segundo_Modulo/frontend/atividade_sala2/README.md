# Sobre a Confecção do Projeto

O desenvolvimento deste formulário foi pensado com base nos princípios da simplicidade e clareza estrutural, ideais para quem está aprendendo a estruturar páginas web:

Separação de Responsabilidades:

index.html: Contém exclusivamente a estrutura semântica da página (cabeçalho, formulário de login com campos de e-mail e senha, rodapé e links de navegação).

style.css: Concentra toda a estilização visual, garantindo que o código HTML permaneça limpo e legível.

Identidade Visual Personalizada:

A paleta de cores foi definida utilizando tons de vermelho e branco, acompanhados por fontes na cor preta padrão, garantindo excelente contraste, legibilidade e um design limpo.

Design Responsivo e Flexível:

Utilização de conceitos modernos do CSS como Flexbox para o alinhamento e centralização do cartão de login, assegurando que o layout se adapte bem à tela.

#📁 Estrutura de Arquivos

/
├── index.html    # Estrutura da página web
└── style.css     # Estilos e regras visuais


#Como Executar o Projeto

Certifique-se de que os arquivos index.html e style.css estão salvos na mesma pasta.

Dê um duplo clique no arquivo index.html ou abra-o utilizando qualquer navegador web moderno (Chrome, Firefox, Edge, etc.).
